ClassConnect consists of a mobile application and a separate admin web application connected through a shared Firebase backend.

Project Overview

ClassConnect is an academic management system consisting of a mobile application for faculty and class representatives and an admin web application for managing institutional data. Both applications share a common Firebase backend for authentication, data management, and communication.

Problem

Academic updates were often scattered across chats and notices, making information difficult to track and manage efficiently.

Solution

ClassConnect brings essential academic tools into a single platform, improving communication, coordination, and accessibility.

Learning Outcomes

Strengthened my understanding of mobile UI design, user flows, Firebase integration, frontend development, and academic workflow planning.

Tide Task Manager

A mobile-first productivity and focus management application designed in Figma. The prototype explores task organization, focus sessions, and distraction-free user experiences through a clean and modern interface.

Project Goal

Create a mobile productivity app that helps users organize tasks, enter focus sessions quickly, and maintain momentum with a calm, modern interface.

Tools Used

Figma, component libraries, mobile UX patterns, design systems, and interactive prototype testing.

Key Screens

Onboarding, task dashboard, focus timer, and task detail screens designed to support deep work and effective task management.

Design Process

Research, sketching, wireframes, high-fidelity UI, and interaction refinement for a frictionless mobile experience.

What I Learned

How to balance clarity and calm in a productivity interface while maintaining consistent visual systems and intuitive mobile flows.
